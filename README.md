# personal-portfolio

A simple responsive personal portfolio landing page for Edwin Segovia.

## Overview

This project is a static HTML and CSS portfolio website built to highlight:
- professional background
- selected projects
- resume access
- contact information

The site is designed to stay clean, modern, and easy to host with GitHub Pages.

## Project Structure

- `index.html` - main one-page portfolio layout
- `mystyle.css` - site styling and responsive layout rules
- `Assets/Public_Safe.pdf` - public-safe resume PDF
- `Assets/images/Edwin.JPG` - profile image

## Featured Sections

- Hero
- About
- Projects
- Resume
- Contact
